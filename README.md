# Titanic-Exploratory-Data-Analysis
Exploratory Data Analysis (EDA) on the Titanic dataset using Python, Pandas, Matplotlib, and Seaborn. Includes data cleaning checks, statistical analysis, visualizations, correlation heatmap, pairplot, and key insights about passenger survival.
# Titanic Dataset – Exploratory Data Analysis (EDA)

## Task 5 – Data Analyst Internship

### 1. Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset using Python. The goal is to identify patterns, trends, relationships and missing values through statistical analysis and visualizations.

### 2. Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

### 3. Dataset Information
- Dataset: Titanic Dataset
- Total Records: 891
- Total Columns: 12
- Duplicate Records: 0

### 4. Analysis Performed
- Dataset inspection using `info()` and `describe()`
- Missing value analysis
- Duplicate checking
- Value counts and frequency analysis
- Survival distribution analysis
- Gender and passenger class analysis
- Age and fare distribution
- Outlier detection using boxplots
- Correlation heatmap
- Pairplot visualization

### 5. Key Findings
- 342 passengers survived.
- 549 passengers did not survive.
- There were 577 male and 314 female passengers.
- Third-class passengers formed the largest group.
- Female passengers had better survival outcomes.
- First-class passengers generally had better survival outcomes.
- The Cabin column contained the highest number of missing values.

### 6. Project Files
- `Titanic_Exploratory_Data_Analysis.ipynb` – Jupyter Notebook containing Python code and analysis.
- `titanic.csv` – Dataset used for analysis.
- `Titanic_EDA_Report.pdf` – PDF report containing findings and conclusions.

### 7. Conclusion
EDA helped identify important patterns and relationships in the Titanic dataset. Data visualization and statistical analysis provided useful insights into passenger survival based on gender, age and passenger class.
